# Product positioning

CallMeMaybe is consent-based AI phone support for Shopify orders. Its defining
constraint is that conversation output is evidence, not authority: eligibility
is deterministic, customer identity is verified before disclosure, and
consequential Shopify actions require merchant approval plus a fresh order check.

The v1 use cases are:

- Customer-requested callbacks about an order, with explicit per-order consent,
  revocation, suppression, quiet hours, attempt limits, and a single-use code.
- Merchant-approved calls to verified official carrier support numbers for a
  package trace.

The product is not a marketing dialer, general call center, autonomous refund or
returns engine, collections tool, or emergency service. Returns, refunds, and
replacements remain proposals requiring merchant action.
