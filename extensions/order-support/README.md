# CallMeMaybe thank-you extension

This post-purchase support banner tells buyers where to request a callback from
their customer account. It appears at `purchase.thank-you.block.render` and does
not make network requests, modify checkout state or totals, collect payment
information, advertise the app, or link away from Shopify.

Run it with the parent app through `npm run dev`, then add the block in the
development store's checkout editor. API version: 2026-07.
